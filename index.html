説明

まず使ってみる

  1. Seed や N を変えると（入力欄の上下ボタンや ↑↓ キーでも切り替えられます）、Input が自動で作り直されます。Output はそのまま残ります。Output が空欄のときは、鏡のない盤面を表示します（N を変えたときは Output の大きさが合わずエラーになるので、出力を貼り直してください）。
  2. 自分の解法を手元で実行し、その出力を Output に貼り付けます（ファイルの読み込みも可）。
  3. 盤面と Score が即座に更新されます。Score は「組の総数 M(M−1)/2 − 転倒数」で、大きいほど良い配置です。

盤面の見方

  • 外周の丸は入力レーザー（入口ポート）、四角は出力ポートで、四角内の数字はそのポートで受信したレーザー番号です。
  • 色はレーザー番号に対応し、番号が大きくなるにつれて青 → 緑 → 赤と変わります。受信ポートを時計回りにたどって色がなめらかに並ぶほど、転倒数が少ない状態です。
  • マス内の斜線は反射鏡で、1 が /、2 が \ です。
  • 「番号を表示」をオンにすると、丸の外側に入口のレーザー番号、四角に受信番号を表示します。
  • 「全経路を表示」をオンにすると、すべての光の経路を薄く描きます。往復で同じ道を通る光は左右にずらして描きます。

光を調べる

  • 丸・四角にカーソルを合わせると、そのレーザーの入口から出口までの経路を太く描き、入口ポートと受信ポートを上に表示します。
  • マスにカーソルを合わせると、そのマスを通る光だけを表示します。
  • 「レーザー番号」に番号を入れるか、丸・四角をクリックすると、その光の表示を固定します。もう一度クリックするか「解除」で戻ります。

手で鏡を置く

  • 「Manual mode」をオンにしてマスをクリックすると、0（空）→ 1（/）→ 2（\）→ 0 の順に切り替わり、Output と Score が更新されます。
  • 「元に戻す」で直前の編集を取り消し、「鏡を消す」で全マスを空にします。

ファイルの読み込み・保存

  • Input / Output 欄のファイル選択で、テキストファイルを読み込めます。
  • 各欄の「保存」で入力・出力をテキストとして保存し、「SVG 保存」で今の盤面を画像として保存します。
