問題

反射鏡で、光を波長順に並べる

  • N×N の盤面（本番は N = 64）に反射鏡を置く
  • 外周に M = 4N 個のポート。上辺の左端から時計回りに 0, 1, … と番号を付ける
  • ポート i から光 Ai が入り、出た先のポートで受信される。受信した番号を B とする
  • B ができるだけ昇順になるように鏡を置く

図は問題文の例（N = 3）。丸 = 入る光の番号、四角 = 受信した番号。光は番号順に色を付けています（紫 = 1 → 赤 = M）。

問題

マスの状態は 3 種類

  • 0 鏡なし。まっすぐ進む
  • 1 / の鏡。上から来た光は左へ
  • 2 \ の鏡。上から来た光は右へ

どの状態でも、マスの 4 辺は 2 本ずつの組に分かれます。光の経路が交差しても影響しません。

光は逆向きにも同じ道を通る。ポート p の光が q に届くなら、q の光は p に届きます。

問題

スコアは「転倒していない組」の数

転倒数 S = i < j かつ Bi > Bj となる組の数

Score = M(M−1)/2 − S

  • 例（M = 12）は S = 28 なので 66 − 28 = 38 点
  • B が昇順なら S = 0 で、スコアは上界 M(M−1)/2 になる
  • 本番（M = 256）の上界は 32,640 点（到達できるとは限らない）

step1 · 何も置かない

鏡なしでは、光はまっすぐ向かいへ

  • 上辺の光は下辺へ、左辺の光は右辺へ届く
  • A はランダムなので、B もランダムな並びになる
  • ランダムな並びの転倒数は、全体の組の数の約半分

まずはここが基準です。上界のちょうど半分くらい。

ランダムな盤面をたくさん作り、一番良いものを出す

  • 時間いっぱい繰り返し、最良の盤面を出力

毎回ゼロから作り直すので、良い盤面に少しずつ近づく仕組みがない。伸びはわずかです。

step4 · 焼きなまし

悪くなる変更も、ときどき受け入れる

  • スコアの変化 Δ が負でも、確率 exp(Δ / T) で採用
  • 温度 T は 3 → 0.1 へ時間とともに下げる
  • はじめは大胆に動き、最後は山登りと同じになる

ところが点は変わりません。評価が遅く、試行回数が足りないからです。ここから先は評価を速くしていきます。

step5 · 差分計算

変わるのは、そのマスを通る光だけ

  • 1 マス変えて行き先が変わるのは、そのマスを通る光（たいてい 2 本）だけ
  • マスの 4 辺から外へ光をたどれば、4 辺の行き先ポートが分かる
  • 新しい状態で 4 辺をつなぎ直し、変わったポートの B だけ更新
  • 転倒数も、変わった位置が関わる組だけ数え直す（O(kM)）

step6 · 入射光の記録

マスに入ってくる光を覚えておけば、たどらなくていい

  • 各マスの 4 つの辺ごとに、その辺から入ってくる光がどのポートから来たかを記録しておく
  • 例: 上の辺から入ってくる光がポート 5 から来たなら、上の辺に「5」と記録する
  • 光は逆向きにも同じ道を通るので、上の辺から外へ出した光はポート 5 に着く
  • だから 4 辺の行き先は、記録を読むだけで分かる（光をたどらなくてよい）

採用したときだけ、変わった光の経路をたどって記録を書き直します。

step7 · 閉路の鏡を外す

閉路の上の鏡は、外してもスコアが変わらない

  • 閉路: どのポートにもつながらない光の輪（図 ① の点線）

step9 は 4 つの部品でできています: ペアへの言い換え、作れる条件、ペアの焼きなまし、盤面の組み立て。

step9 · 1/4 言い換え

盤面は「ポートを 2 個ずつ組にする方法」

  • 光は逆向きにも同じ道を通るので、p → q なら q → p
  • 盤面全体では、M 個のポートを M/2 組のペアに分けている
  • 例: ポート 3 と 10 がペアなら、ポート 3 で受信するのはポート 10 から入った光（B3 = A10、逆に B10 = A3）
  • スコアはペアの組み方だけで決まる

鏡ではなく、ペアの組み方を直接焼きなましで探します。

step9 · 2/4 作れる条件

どの切断線も、またぐペアが多すぎなければ作れる

  • 光の経路は、隣り合うマスの境界を共有しない道
  • 盤面を 2 つに分ける切断線をまたげる光は、線が横切る辺の数まで
  • 上辺の位置 t と下辺の位置 b を結ぶ線なら N + |t − b| 本（左右を結ぶ線も同様）
  • Okamura–Seymour の定理: すべての切断線でこれを満たせば、必ず鏡で作れる

切断線は 2(N−1)² 本。それぞれの余裕を bitset で持ち、余裕 0 の線をまたぐペアが増える変更は採用しない。

step9 · 3/4 焼きなまし

2 組のペアを組み替える

  • 2 組のペアを選び、相手を交換する。例: ペア 3–10 と 5–20 → 3–20 と 5–10
  • B が変わるのは 4 か所だけ。転倒数の差分はすぐ計算できる
  • 焼きなましで採用しそうなときだけ、切断線の条件を調べる

1 回の試行が鏡の変更よりずっと軽く、しかも盤面の中の細かい形を気にしなくてよい。

図は N = 8。弦 = ペア、外側の四角 = 受信番号 B。

step9 · 4/4 組み立ての準備

仮のペア: 本当のペアを、交差しないように組み直したもの

  • 1. ペア → 括弧列: 各ペアで、番号の小さい方のポートを「(」、大きい方を「)」にする。ポート 0, 1, 2, … の順に並べると括弧列になる
  • 2. 括弧列 → 仮のペア: この括弧列を、ふつうの括弧の対応（いちばん近い「(」と「)」から閉じる）で組み直す
  • 3. 仮のペアは入れ子なので交差しない。本当のペアは交差してもよい
  • 例: 本当のペア 1–3、2–4 → 「( ( ) )」→ 仮のペア 2–3、1–4
  • どちらも「(」と「)」の組。次のページでは「)」から出発し、「(」をゴールに経路を引く

step9 · 4/4 組み立て

最良のペアから、鏡の配置を組み立てる

  • Wagner–Weihe のアルゴリズムで、隣り合うマスの境目を 2 本の経路が共有しないように、全ペアに経路を引く
  • ① 向きを付ける: 仮のペア（前のページ）ごとに、右手を壁につけて歩く経路を引き、通った境目に矢印を付ける
  • ② 本当のペアを引く: 1 組ずつ、矢印の向きだけを通り、まだ使っていない境目を右手優先で進む
  • ③ 状態を決める: 各マスで経路がつないだ 2 辺から、状態 0 / 1 / 2 が決まる

step9 · 4/4 組み立て（補足）

なぜ ② で本当のペアを引けるのか

  • ① の矢印は、「)」のポートから流れ出して「(」のポートに流れ込む流れになっている
  • どのマスでも、入る矢印と出る矢印の数が同じ（図の枠のマス）
  • だから「)」から矢印に沿って進むと、行き止まらずに、どこかの「(」に必ず着く
  • 正しい相手の「(」に着くように、右手優先で進み、引く順番も決めている。切断線の条件を満たしていれば必ずうまくいくことが、Wagner–Weihe の論文で証明されている

実装では最後に全ポートから光をたどり、ペアどおりか確かめる。100 ケースで失敗 0。
